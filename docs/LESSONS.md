# Lessons and open questions

- Frame metrics can reward a flickering output; the competition ranks possession spells, so report both.
- IDSSE and Metrica labels come from different operational rules; source-aware error analysis is required.
- Three full matches are a small validation sample; inspect each game and the worst-case result.
- Resolve Metrica sample-data rights before committing derived weights or data.
- A clean public release must regenerate the exact submitted CSV from code and authorized assets.
