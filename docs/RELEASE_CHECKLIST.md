# Public release gates

- [ ] Select a model using grouped leave-one-Metrica-match-out evaluation; publish per-game and worst-case metrics.
- [ ] Verify the final source, model/config hashes, and exact deterministic submission regeneration.
- [ ] Resolve rights for every training dataset, trained weight, and derived artifact; especially Metrica sample data.
- [ ] Keep raw tracking/events/labels, private ground truth, predictions, submissions, and caches out of Git.
- [ ] Scan the full new history for credentials and accidentally committed data.
- [ ] Review every model weight for provenance and redistribution permission; include required attributions.
- [ ] Replace staging language with verified method, commands, and evidence.
- [ ] Keep repository private until the team is ready to publish.
